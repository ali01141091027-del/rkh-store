Files:

Before publishing:
1. Open script.js.
2. Replace RKH_WHATSAPP with the real WhatsApp number in international format, without + or spaces.
   Example for an Egyptian number 01012345678: 201012345678
3. Replace RKH_FACEBOOK with the real Facebook page/profile URL.
4. Replace the sample products in the products array with the real products.
5. Product prices are intentionally NOT displayed. "ASK FOR PRICE" opens WhatsApp with the product name.
